# Install v4.9.5 Android

1. Ekstrak ZIP patch ke folder repository.
2. Jalankan `node -p "require('./package.json').version"` dan pastikan 4.9.5.
3. Jalankan `npm test`.
4. Commit dan push ke GitHub.
5. Setelah GitHub Pages selesai deploy, buka `refresh-495.html` satu kali.
6. Uji Replay dan Love Cinema.

Tidak perlu menjalankan SQL Supabase lagi.
